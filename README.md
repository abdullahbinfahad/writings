# ✍️ Writings

> A collection of my original writings, articles, blog posts, stories, reflections, and website content.

Welcome to my public writing archive. Everything here is written by me — essays, articles, stories, and notes on technology, engineering, student life, and ideas worth keeping.

## 🌐 Read online

**https://posts.abdullahbinfahad.info**

All posts are published as a readable blog, with an archive page and an index of everything written so far.

## 📚 What's inside

- **Articles** — longer pieces on technology, engineering, and building things
- **Blog posts** — shorter updates, notes, and observations
- **Stories** — original fiction and creative writing
- **Reflections** — personal essays and lessons learned
- **Website content** — copy and pages written for my own projects

## 🛠️ How this site is built

This is a Jekyll site. Posts live in `_posts/`, layouts in `_layouts/`, and the published pages are generated from Markdown — simple, fast, and easy to search.
